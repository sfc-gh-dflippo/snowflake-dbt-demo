SSC-EWI-DBTARC0001 - Model outside a recognised layer folder
information

The model path does not match a layer folder recognised by this linter.

Layer folders let a project apply shared configuration to groups of models. This rule checks folder names. A folder that has its own models: configuration in dbt_project.yml counts as a layer, whatever its name. A model outside a recognised layer can still inherit project configuration.

The bronze/silver/gold layout is a local convention, not a dbt requirement. Waive this rule if the project uses another layout or has not yet been restructured after conversion.

References

  • [dbt staging models](https://docs.getdbt.com/best-practices/how-we-structure/2-staging)
  • [dbt materializations](https://docs.getdbt.com/docs/build/materializations)

Remediation

If the project uses layers, move the model to the folder that matches its role. Check the inherited configuration after the move.

Review the rule guidance and conditions before using this alternative.

select * from {{ source('crm','accounts') }}  -- models/misc/accounts.sql
